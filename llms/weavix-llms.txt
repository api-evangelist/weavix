# weavix

> weavix is the "Internet of Workers" frontline communication and workforce productivity platform, built around walt, a purpose-built smart radio for industrial deskless workers. Its public REST API lets administrators automate the platform from outside systems: manage crafts, sites, geofences and permission groups; create and manage users; send messages to channels and individual users; retrieve message history and form submissions; and trigger mass alerts. Authentication uses an account API key sent in the Authorization header.
